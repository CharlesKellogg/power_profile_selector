# power_profile_selector

Simple TUI wrapper for [powerprofilesctl](https://man.archlinux.org/man/powerprofilesctl.1.en), built with [Ratatui](https://ratatui.rs) using the [Simple Template](https://github.com/ratatui/templates/tree/main/simple).

This is my first project with Rust!

## Dependencies

- [power-profiles-daemon](https://gitlab.freedesktop.org/upower/power-profiles-daemon) (I believe this only runs on Linux)
